# سياسة الاستخدام المقبول

*الإصدار {{doc.version}}، آخر تحديث {{doc.updated}}.*

تُعدّ هذه السياسة جزءاً من [شروط الخدمة]({{url.terms}}). وتسري على كل من يستخدم {{product.name}} والخدمات الأخرى التابعة لـ{{company.name}}، بمن فيهم مستخدموك والمستخدمون النهائيون، وكل من يتصرف باستخدام بيانات اعتمادك أو مفاتيحك. **أنت مسؤول عن كل استخدام لحسابك، وعن ضمان التزام كل من تسمح له بالدخول بهذه السياسة.** والأمثلة الواردة أدناه توضيحية ولا تحصر ما هو محظور؛ فكل ما يكون ضاراً أو غير قانوني غير مسموح به، حتى لو لم يرد ذكره.

## 1. الأسس القانونية والسلامة {#legal}

لا يجوز لك استخدام الخدمات من أجل:

1. مخالفة أي قانون أو لائحة، أو مساعدة الغير على ذلك، بما في ذلك قوانين حماية المستهلك والإعلان وحماية البيانات والتصدير والعقوبات ومكافحة غسل الأموال والمقامرة والملكية الفكرية؛
2. إنشاء **مواد استغلال الأطفال جنسياً أو الإساءة إليهم** أو تحميلها أو تخزينها أو مشاركتها أو الإشارة إليها، أو أي محتوى يُضفي طابعاً جنسياً على القاصرين بأي شكل. وتُطبّق في ذلك سياسة عدم التسامح المطلقة: نزيل المحتوى، ونغلق الحساب، ونحفظ الأدلة، ونبلّغ السلطات المختصة والخطوط الساخنة المعنية دون إشعار مسبق؛
3. الترويج للعنف أو الإرهاب أو التطرف العنيف أو إيذاء النفس أو اضطرابات الأكل، أو تهديد أي أحد بها أو التخطيط لها أو الاحتفاء بها، أو التحريض على الكراهية أو التمييز ضد أشخاص بسبب خصائص محمية؛
4. التحرش أو التعقب أو التنمر أو التهديد أو التخويف أو كشف المعلومات الخاصة بأي شخص أو نشرها، أو مشاركة صور حميمة لشخص دون موافقته (بما في ذلك الصور المُصطنعة أو “المزيفة”)؛
5. الاحتيال على الناس أو خداعهم أو تضليلهم، بما في ذلك عمليات النصب، والتصيد الاحتيالي، ومخططات الهرم وبونزي، والمراجعات والشهادات المزيفة، والمتاجر الوهمية، وانتحال الشخصية، والسلع المقلّدة، أو الاستخدام الاحتيالي لوسائل الدفع؛
6. بيع أو عرض أو تسهيل السلع أو الخدمات غير المشروعة، بما في ذلك المخدرات والأسلحة والمتفجرات، والبيانات أو بيانات الاعتماد المسروقة، والوثائق المزورة، والاتجار بالبشر، أو الخدمات المنظمة غير المرخّصة؛
7. تشغيل ألعاب قمار أو يانصيب أو سحوبات غير مرخّصة، أو أي نشاط يتطلب ترخيصاً لا تملكه؛
8. {{#if feature.uploads}}تحميل صور أو ملفات أو بيانات لا تملكها أو لا تملك إذناً باستخدامها، أو تُظهر أشخاصاً آخرين أو تُعرّف بهم دون موافقتهم، أو {{/if}}انتهاك حقوق الغير في حقوق النشر أو العلامات التجارية أو الأسرار التجارية أو الخصوصية أو الشهرة أو غيرها من الحقوق، أو توزيع برمجيات أو وسائط مقرصنة أو مكسورة الحماية.

## 2. الأمن وإساءة استخدام النظام {#security}

لا يجوز لك:

1. إدخال أو توزيع البرمجيات الخبيثة، أو برمجيات الفدية، أو برمجيات التجسس، أو مُعدّنات العملات الرقمية، أو أدوات التحكم في الشبكات الآلية (botnets)، أو أي شيفرة ضارة؛
2. محاولة الوصول غير المصرّح به إلى الخدمات أو إلى حسابات أخرى أو إلى أنظمتنا أو بيانات عملاء آخرين أو الشبكات المتصلة بها، أو اختبار ثغراتها أو فحصها أو تجربتها **دون إذن كتابي مسبق منا** (والاستثناء الوحيد هو البحث بحسن نية وفق سياسة [الأمن والإفصاح عن الثغرات]({{url.security}}) الخاصة بنا)؛
3. تنفيذ هجمات الحرمان من الخدمة، أو حشو بيانات الاعتماد، أو القوة الغاشمة، أو التعداد، أو أي هجمات أخرى، أو المساعدة على تنفيذها، أو استخدام الخدمات كمنصة لمهاجمة أطراف ثالثة؛
4. تجاوز ميزات المصادقة، أو حدود المعدل، أو الحصص، أو القياس، أو القيود الجغرافية، أو مكافحة الإساءة، أو تصفية المحتوى، أو ميزات الأمان، أو تعطيلها أو التدخل فيها؛
5. اعتراض حركة المرور أو البروتوكولات أو التلاعب بها، أو تشغيل وكلاء (proxies) غير مصرّح بها، أو محاكيات، أو عملاء معدّلين؛
6. إثقال الخدمات أو الإضرار بتجربة المستخدمين الآخرين، بما في ذلك الطلبات الآلية المفرطة، وأي استخدام يفرض حملاً غير متناسب على بنيتنا التحتية (ويجوز لنا تحديد حدود “للاستخدام العادل” لأي خطة وفرضها)؛
7. استخدام الخدمات لإرسال **الرسائل المزعجة (spam)**، أو الرسائل الجماعية غير المطلوبة، أو التسويق المضلل أو المستهدف بصورة غير مشروعة، أو لجمع عناوين البريد الإلكتروني أو البيانات الشخصية؛ ويجب أن تتوافق الرسائل المرسلة عبر الخدمات مع قوانين مكافحة الرسائل المزعجة والخصوصية الإلكترونية (الموافقة، والتعريف بالمرسل، وآلية إلغاء اشتراك فعّالة)؛
8. محاولة استكشاف نقاط الضعف في تطبيقات المستخدمين الآخرين أو بياناتهم التي تصل إليها عبر الخدمات أو استغلالها؛
9. محاولة قراءة بيانات تخص حسابات أو مؤسسات أخرى أو تغييرها أو حذفها، بما في ذلك عن طريق تخمين المعرّفات أو الروابط أو عناوين الملفات أو تعديلها.

## 3. نزاهة المنصة {#integrity}

لا يجوز لك:

1. إنشاء حسابات متعددة أو مزيفة للتحايل على حظر أو حد أو حصة أو تجربة أو سعر أو قاعدة إحالة أو عرض ترويجي، أو للتلاعب بالترتيب أو التصويت أو التقييمات أو المقاييس؛
2. مشاركة الحسابات أو بيعها أو تأجيرها أو نقلها، أو مشاركة المقاعد أو مفاتيح API أو التراخيص أو بيعها أو تأجيرها أو نقلها؛
3. إعادة بيع الخدمات أو توفير الوصول إليها لأطراف ثالثة، إلا بالقدر الذي تسمح به خطتك صراحةً؛
4. كشط البيانات من الخدمات أو زحفها أو جمعها أو تحميلها بكميات كبيرة، أو بناء قواعد بيانات مشتقة منها، إلا عبر واجهة البرمجة الموثّقة وضمن حدودها وشروطها؛
5. الهندسة العكسية لاستخراج الشيفرة المصدرية أو النماذج أو المطالبات (prompts) أو الأوزان أو الواجهات غير العامة، أو استخدام الخدمات أو مخرجاتها لبناء منتج أو نموذج منافس أو تدريبه أو تحسينه، ما لم نتفق على ذلك كتابةً؛
6. تقديم هوية غير صحيحة عن نفسك أو انتمائك أو صلاحياتك، أو استخدام اسمنا أو علامتنا التجارية أو شعاراتنا بطريقة توحي بالتأييد؛
7. إساءة استخدام عمليات الفوترة والاسترداد والاعتراض على المدفوعات (chargeback) والائتمان والدعم، بما في ذلك المطالبات الكاذبة المعروفة بعدم التسليم أو الاستخدام غير المصرّح به؛
8. استخدام الخدمات للتحايل على قواعد منصة تابعة لطرف ثالث أو شروط شخص آخر.{{#if feature.game}}
9. الغش، أو استخدام الروبوتات أو البرمجيات غير المصرّح بها، أو استغلال الأخطاء، أو تداول الحسابات أو العناصر الافتراضية مقابل المال الحقيقي، أو التعزيز المصطنع للتقدم، أو التلاعب بنتائج الألعاب أو ترتيبها أو آلية المطابقة فيها. وترد القواعد التفصيلية وإشعار مكافحة الغش والعقوبات في [سياسة قواعد اللعب والعناصر الافتراضية]({{url.game_rules}}).{{/if}}

## 4. قواعد المحتوى {#content}

{{#if feature.ugc}}
لا يجوز أن يكون المحتوى الذي تحمّله أو تنشره:

1. غير مشروع، أو تشهيرياً، أو فاحشاً، أو إباحياً (ما لم تسمح ميزة محددة صراحةً بالمحتوى البالغين بصورة مشروعة ومع التحقق من العمر)، أو عنيفاً بشكل مفرط، أو مخالفاً بأي صورة أخرى للقسم 1؛
2. متضمناً بيانات شخصية للغير (بيانات اتصال، أو هويات، أو بيانات مالية، أو بيانات صحية، أو صوراً أو تسجيلات لأشخاص) دون أساس قانوني وموافقتهم عند الاقتضاء؛
3. متضمناً معلومات مضللة مصممة للإضرار، مثل معلومات طوارئ مزيفة، أو التدخل في الانتخابات، أو السلوك المنسّق غير الأصيل؛
4. وسائط اصطناعية مضللة (بما في ذلك استنساخ الصوت والوجه) لأشخاص حقيقيين دون موافقتهم، أو محتوى مولّد بالذكاء الاصطناعي لا تضع عليه علامة توضح ذلك حين يقتضي القانون أو منصة ما ذلك؛
5. مخفياً أو متعقِّباً أو ضاراً: مثل البكسلات المتعقّبة، أو أدوات تتبع الويب، أو ملفات تعريف الارتباط، أو النصوص البرمجية التي تجمع بيانات من مستخدمين آخرين دون علمهم والموافقة المطلوبة.

نحن لا نفحص المحتوى مسبقاً، لكننا نتصرف بناءً على البلاغات وعلى نتائجنا الخاصة (القسم 8).

## 5. إساءة استخدام الذكاء الاصطناعي {#ai}

{{#if feature.ai}}
علاوةً على القواعد السابقة، لا يجوز لك استخدام ميزات الذكاء الاصطناعي من أجل:

1. توليد برمجيات خبيثة، أو تصيّد احتيالي، أو عمليات نصب، أو تحرش مستهدف، أو تعليمات أسلحة أو تعليمات ضارة جسيمة أخرى؛
2. إنتاج محتوى لصور حميمة غير متفق عليها، أو انتحال شخصية، أو أدلة مزيفة؛
3. اتخاذ قرارات آلية كاملة لها آثار قانونية أو آثار مماثلة جسيمة على الأشخاص (في التوظيف، والائتمان، والإسكان، والتأمين، والتعليم، والمزايا العامة، وإنفاذ القانون، والهجرة، والرعاية الصحية) دون مراجعة بشرية ذات معنى، وحيثما يسمح القانون بذلك؛
4. إجراء التعرف على المشاعر في العمل أو المدرسة، أو تصنيف القياسات الحيوية حسب السمات الحساسة، أو التقييم الاجتماعي، أو كشط الصور الوجهية بصورة عامة وغير مستهدفة، أو غير ذلك من الممارسات المحظورة بموجب التنظيمات المطبقة للذكاء الاصطناعي (بما في ذلك قانون الذكاء الاصطناعي الأوروبي)؛
5. محاولة حقن المطالبات (prompt injection)، أو كسر القيود (jailbreaking)، أو استخراج موجّه النظام، أو استخراج النموذج، أو إبطال أنظمة السلامة، أو تدريب نموذج آخر على المخرجات حيثما يكون ذلك محظوراً في وثائقنا؛
6. عرض مخرجات الذكاء الاصطناعي على أنها استشارة مهنية (قانونية أو طبية أو مالية)، أو على أنها من إنتاج بشري حيثما يؤدي ذلك إلى الخداع.
{{else}}
إذا أضافت الخدمات ميزات مدعومة بالذكاء الاصطناعي، فإن القواعد الخاصة بها (عدم التوليد الضار، وعدم الانتحال أو التزييف العميق، وعدم اتخاذ قرارات آلية جسيمة دون مراجعة، وعدم محاولة إبطال أنظمة السلامة) تسري من تلك اللحظة.
{{/if}}

## 6. الاستخدام المنظّم وعالي المخاطر {#high-risk}

ما لم نتفق على خلاف ذلك كتابةً، لا يجوز استخدام الخدمات في: خدمات الطوارئ؛ أو التشخيص الطبي أو العلاج الطبي؛ أو البنية التحتية الحرجة أو السلامة الصناعية؛ أو التحكم في المركبات أو الطيران أو الأسلحة؛ أو بيانات بطاقات الدفع أو البيانات الصحية أو غيرها من البيانات المنظّمة التي لم تُصمَّم بنيتنا التحتية لحفظها. وأنت مسؤول عن أي تراخيص أو شهادات أو موافقات يتطلبها استخدامك.

## 7. الاستخدام العادل للخطط المجانية والترويجية {#fair-use}

الخطط المجانية والتجارب والعروض الترويجية مخصصة للتقييم الحقيقي والاستخدام الشخصي أو على نطاق صغير. ويُعدّ استخدامها لتشغيل أعباء إنتاجية واسعة النطاق، أو لتعدين الموارد، أو لإعادة البيع، أو بالتسجيل المتكرر من جديد، إساءةً للاستخدام. ويجوز لنا فرض حدود معقولة، وقد نطلب الترقية، دون إشعار مسبق حين تكون الإساءة آلية أو واضحة.

## 8. الإنفاذ {#enforcement}

قد نحقق في الانتهاكات المشتبه بها، و**وفقاً لتقديرنا ومع التناسب مع خطورة الانتهاك وتكراره ونيته وضرره**، قد نتخذ أياً من الإجراءات التالية، منفردةً أو مجتمعةً، مع الإشعار المسبق أو دونه حيثما يسمح القانون بذلك:

1. تحذيرك أو مطالبتك بمعالجة المشكلة؛
2. إزالة المحتوى أو تعطيله أو وضع علامة عليه أو خفض ترتيبه أو تقييد ظهوره؛
3. تقليص أو تقييد أو حجب الميزات أو مفاتيح API أو عناوين IP أو حركة المرور؛
4. تعليق الحساب مؤقتاً أو تقييد وظائفه؛
5. إنهاء الحساب ومنع مالكه من التسجيل من جديد (انظر القسم 17 من الشروط)؛
6. حجب المدفوعات أو تسويتها معها، ورفض الاسترداد عن فترات الانتهاك؛
7. استرداد تكاليفنا والسعي إلى أوامر قضائية زجرية وغيرها من أشكال الإغاثة القانونية (القسم 21 من الشروط)؛
8. إخطار المستخدمين المتأثرين والمنصات ومزودي خدمات الدفع، و**الإبلاغ عن ذلك إلى جهات إنفاذ القانون أو الجهات الرقابية**، والاحتفاظ بالسجلات والإفصاح عنها بالقدر الذي يسمح به القانون أو يقتضيه.

تؤدي الانتهاكات الجسيمة أو غير المشروعة (مثل استغلال الأطفال، والبرمجيات الخبيثة، والاحتيال، والضرر الوشيك، والهجمات على أنظمتنا) إلى الإنهاء الفوري. ولا نتحمل المسؤولية عن الخسارة الناتجة عن الإنفاذ المتخذ بحسن نية وفق هذه السياسة. وقد نتصرف أيضاً بناءً على أوامر المحاكم، وطلبات السلطات، والبلاغات الصادرة عن أصحاب الحقوق.

**حقك في المعرفة والاعتراض.** حيثما يقتضي القانون ذلك (مثل قانون الخدمات الرقمية الأوروبي (DSA))، عندما نزيل محتوى أو نقيّد حسابك أو ننهيه، نُبلغك بالوقائع والأسباب، وبما إذا كانت أدوات آلية قد استُخدمت، وبكيفية الطعن في القرار. ويمكنك طلب مراجعة بشرية لأي قرار إنفاذ بمراسلة [{{company.legal_email}}](mailto:{{company.legal_email}}) خلال **6 أشهر**؛ نرد بسرعة، ونلغي الإجراء إذا كنا قد أخطأنا. وقد تُهمل الاعتراضات أو البلاغات المسيئة أو المتكررة بسوء نية أو التي لا أساس لها.

## 9. الإبلاغ عن الإساءة {#reporting}

أبلِغ عن الانتهاكات أو المحتوى غير المشروع أو مشكلات الأمان أو الاشتباه في اختراق الحساب عبر [{{company.legal_email}}](mailto:{{company.legal_email}}). يُرجى تضمين الرابط أو المعرّف، ووصفاً لسبب كونه مشكلة، وبيانات الاتصال الخاصة بك. أما إشعارات حقوق النشر والإشعارات المماثلة فراجع [إشعارات حقوق النشر والمحتوى غير المشروع]({{url.copyright}})؛ وبشأن الثغرات البرمجية راجع [الأمن والإفصاح عن الثغرات]({{url.security}}). وإذا كان شخص ما في خطر داهم، فاتصل أولاً برقم الطوارئ المحلي.

نرحب بالبلاغات الحسنة النية. ولا تسيء استخدام آلية الإبلاغ: فالبلاغات الكاذبة عن علم أو بسوء نية أو التي تتضمن تحرشاً قد تشكّل هي ذاتها انتهاكاً لهذه السياسة.
