# セキュリティおよび脆弱性の開示

*バージョン {{doc.version}}、最終更新日 {{doc.updated}}。*

当社はセキュリティを重視しており、研究者からの誠実な報告を歓迎します。連絡先：[**{{company.email}}**](mailto:{{company.email}})。

## 1. 対象範囲 {#scope}

対象範囲内：{{product.name}}、{{company.website}}、および当社が運営する自社のサブドメイン、アプリケーションならびにAPI。**対象範囲外**：第三者のサービスおよびインフラ、他のお客様のアカウントおよびデータ、当社の従業員またはユーザーに対するソーシャルエンジニアリングまたはフィッシング、物理的な攻撃、サービス妨害（DoS）および大量トラフィックによるテスト、スパム、ならびに非現実的なユーザー操作または古いソフトウェアを必要とする発見事項。

## 2. テストの規則 {#rules}

誠実にテストを行う場合、以下を遵守しなければなりません。

- ご自身のアカウントおよびデータに対してのみテストすること。他者のデータに到達した場合は直ちに中止して報告し、問題を示すために必要な範囲を超えて、当該データにアクセス、ダウンロード、変更または保持しないこと。
- サービスを低下させないこと、大量の自動スキャンを実行しないこと、ならびに永続化、横展開または情報の持ち出しのためにエクスプロイトを使用しないこと。
- 当社が問題を修正するための合理的な期間を得るまで（報告から**90日間**、または当社が合意した場合はそれより早く）、問題を第三者に開示せず、詳細を公表しないこと。
- 法令および本規則に従うこと。

## 3. セーフハーバー {#safe-harbour}

本ポリシーを遵守される場合、当社はお客様の調査を許可されたものとして扱い、当該調査を理由とする法的措置の追及またはアカウントの解約を行わず、これらを支援もしません。また、問題の把握と解決に向けてお客様と協力します。これは、第三者に対して法令に違反する行為を許可するものではなく、第三者は独自に行動する場合があります。ご不明な点がある場合は、まずお問い合わせください。

## 4. 報告内容 {#report}

脆弱性の明確な説明、影響を受けるURLまたはコンポーネント、再現手順または概念実証（PoC）、影響、お客様の連絡先、ならびに謝辞（クレジット）の掲載を希望されるかどうか。可能であれば、機密性の高い資料は暗号化してください。当社の鍵が必要な場合はお申し出ください。

## 5. その後の流れ {#process}

当社は、報告を受領確認し、優先度を判定し、経過をお客様にお知らせし、深刻度に応じて修正を行い、ご希望があればお客様の功績を表示します。現在、有償の報奨金プログラムは実施しておらず、報酬をお約束することはできませんが、感謝の言葉またはノベルティグッズをお贈りする場合があります。

## 6. ユーザーの方へ：アカウントの保護 {#users}

他と重複しない強力なパスワードを使用し、提供されている場合は多要素認証を有効にし、ソフトウェアを最新の状態に保ち、フィッシングに注意し、不正アクセスの疑いがある場合は速やかに[{{company.email}}](mailto:{{company.email}})までご報告ください。脆弱性を悪用したり、本ポリシーの範囲外でテストを行ったりすることは、[利用ポリシー]({{url.acceptable_use}})に違反します。
